# 🐾 天使柯基「魯尼」與哈士祈的幸福農場 (Angel Corgi Rooney & Husky Farm)

一個溫馨療癒的網頁農場模擬小遊戲。玩家扮演一隻擁有金黃光環與潔白小翅膀的天使柯基**魯尼**，一邊打理農田種植甘甜多汁的美味瓜果，一邊陪伴照顧自己收養的帥氣**哈士祈**！

## 🍉 預設三種精選瓜果種子

進入遊戲一開始即預設擁有三種消暑甘甜瓜類種子各 5 顆：
1. **🍉 無籽西瓜**：汁多甜脆、消暑解渴，完全沒有籽的極致消暑西瓜！
2. **🍈 哈密瓜**：細緻網紋、散發濃郁芳香與甘甜果肉的頂級哈密瓜！
3. **🍈 香瓜**：金黃亮眼果身、口感清脆清甜的翠玉甜香瓜！

## ⭐ 農作物品階系統 (一星～五星)

- **品階劃分**：每種作物收成時皆分為 **一星（普通）**、**二星（優良）**、**三星（特級）**、**四星（頂級）**、**五星（神品）**。
- **等級越高，高品階機率越大**：
  - 農場等級提升時，低星級權重下降，高星級（尤其 4星 與 5星）產出機率顯著大幅提升！
  - 田間成熟的作物會即時在頭頂飄浮顯示對應品階星芒徽章，一目了然！
- **價值越高**：
  - 品階越高，作物於雜貨店的販賣售價成倍數翻漲（五星神品售價高達 6.5 倍）！
  - 同時收成時可獲得倍數膨脹的豐厚農場升級經驗值。
  - 餵食狗勾高等級品階作物，飽足度與心情值也將獲得額外加成！

## 📖 作物品階圖鑑系統 (Compendium)

點擊頂部快捷按鈕 **「📖 作物圖鑑」** 隨時開啟圖鑑專屬介面：
- **全品階解鎖進度**：即時統計已收錄品階數與解鎖百分比（例如 15/15 100%）。
- **實時機率換算**：根據當前農場等級，即時顯示 1星～5星 之精確收成掉落機率。
- **作物品階圖卡**：
  - 詳列所有作物的 5 個品階卡牌槽位。
  - 已解鎖之品階會點亮專屬星芒徽章、等級名稱、加成售價與累積收成次數。
  - 達成 5 品階全收錄將獲頒 **「👑 全品階達成」** 榮耀標記！
  - 首度收成全新未解鎖品階時，田間將跳出專屬解鎖驚喜浮動提示！

## 🔄 如何重置遊戲進度？

若想重新體驗農場養成、清除金幣與重練圖鑑，可使用以下幾種便利方式：

1. **方式一（遊戲內按鈕 - 最推薦）**：
   - 點擊頂部 **「📖 作物圖鑑」**，在視窗最下方點擊 **「🔄 重置遊戲進度」** 紅色按鈕。
   - 或點擊頂部 **「⚙️ 管理員」**（輸入密碼 `0929`），在管理後台最下方點擊 **「⚠️ 重置遊戲進度」**。
   - 確認後即可將農場等級、經驗值、金幣（恢復 60 幣）、背包瓜果種子與圖鑑全部恢復為全新初始狀態！

2. **方式二（瀏覽器控制台 - 完全出廠重置）**：
   - 在遊戲畫面中按下鍵盤 <kbd>F12</kbd> 打開開發者工具。
   - 切換至 **Console (主控台)** 分頁，輸入以下指令並按 Enter：
     ```javascript
     localStorage.clear(); location.reload();
     ```
   - 頁面重新整理後即徹底恢復至原始預設狀態（包含自訂圖片與後台設定全部重置）。
